# Working notes for contributors

Trust Archive is a small notebook, not a directory of people. Each entry should answer one clear question about public information.

## Before publication

- Confirm that an original source is publicly accessible.
- Record the date the source was observed. A publication date and an observation date are not interchangeable.
- Keep quotations brief; describe the context around them.
- Separate observed facts from interpretations.
- Don't infer a person's identity from a shared username.
- If a source changes, update the note without silently replacing a dated observation.

## Filenames

Public field notes use a two-digit series number. Keep the first line of the file aligned with the reading edition's title.

## Corrections

Make a new commit for a material correction. Include the record number and explain what changed in normal language. Spelling and layout-only edits need no extended explanation.
