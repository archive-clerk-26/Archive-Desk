# TA-01 · A page changes. Its address doesn't.

Published: 2026-10-04  
Subject: Public records

A link shows the present copy of a document. It does not always establish what the document said when it was first released.

## Editorial scope

This note covers the difference between a live page, a dated observation and an earlier working copy. It does not assume that every removed line was removed for a significant reason.

## Source handling

Keep the address, observation date and exact claim together. If a historical version is available, identify it as historical rather than presenting it as the current page.

## Reading-edition summary

When two copies disagree, compare the evidence for each version and state what can actually be verified. A changed page is not, by itself, proof of wrongdoing.
